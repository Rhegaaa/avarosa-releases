# AVAROSA — versions Windows

Ce dépôt distribue les installateurs Windows et leurs manifestes de mise à jour signés. Il ne contient pas de données de joueurs ni de clés secrètes.

[Télécharger la dernière version](https://github.com/Rhegaaa/avarosa-releases/releases/latest)

Ouvrez l’installateur, puis utilisez le raccourci AVAROSA du Bureau. Pour connecter votre compte, ouvrez League of Legends puis choisissez « Mon profil → Connecter mon client LoL » dans AVAROSA. Aucun mot de passe Riot n’est demandé par AVAROSA.

Les mises à jour sont téléchargées en arrière-plan et installées à la fermeture de l’application. Les données restent sur votre ordinateur.

Application indépendante, non affiliée à Riot Games. L’installateur Windows n’est pas encore signé Authenticode.
